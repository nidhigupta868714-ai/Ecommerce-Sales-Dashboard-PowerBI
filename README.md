# 📊 E-Commerce Sales Dashboard | Power BI

## 📌 Project Overview

An interactive **Power BI Dashboard** built to analyze e-commerce sales performance across multiple categories, states, and payment modes using real transactional data.

---

## 📂 Dataset

- **Orders.csv** – 500+ records containing Order ID, Order Date, Customer Name, State, City
- **Details.csv** – 1,500+ records containing Amount, Profit, Quantity, Category, Sub-Category, Payment Mode
- **Categories:** Clothing, Electronics, Furniture

---

## 🚀 Key Features

- Connected two tables (Orders + Details) using **Data Modelling**
- Created **DAX measures** for Revenue, Profit, and Quantity KPIs
- Interactive filters by **Region, Category, and Payment Mode**
- Visualized sales trends by **state, category, and customer segment**
- Clean and user-friendly dashboard layout

---

## 🛠️ Tools & Technologies

- Power BI Desktop
- DAX (Data Analysis Expressions)
- Data Modelling
- Power Query (ETL)
